# ¿Le pusimos precio al Sol?

Proyecto de Introducción a la Ciencia de Datos,

## Objetivo principal

Caracterizar la relación entre la necesidad energética y la posibilidad económica de cubanos con la oferta del mercado solar.

## Enfoque de investigación

El proyecto sigue el hilo conductor:

**NECESIDADES > CAPACIDAD ECONÓMICA > OFERTAS > ADECUACIÓN/BRECHAS**

Se busca estudiar las necesidades energéticas de las personas,sus posibilidades económicas, la oferta solar observada en Cuba y los posibles desajustes entre estos elementos.
