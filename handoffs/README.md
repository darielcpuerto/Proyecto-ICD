# Handoffs

Carpeta para los traspasos de sesión del proyecto. Cada archivo resume el
estado del trabajo al cierre de una sesión: objetivo, qué se hizo, archivos
clave, cómo ejecutar y probar, resultados verificados, bloqueos, pendientes y
restricciones.

## Convención

- Un archivo por sesión: `AAAA-MM-DD-tema.md`
  (por ejemplo `2026-10-15-herramienta-recoleccion-web.md`).
- No sustituyen a `journal/JOURNAL.md` (diario cronológico del proyecto) ni a la
  documentación de `referencias/`: la complementan para retomar el trabajo.
- No se renombran ni se borran; si una sesión continúa otra, se añade un archivo
  nuevo.
