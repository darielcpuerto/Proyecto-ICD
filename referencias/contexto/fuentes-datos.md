# Fuentes de datos

El proyecto utiliza obligatoriamente tres categorías de fuentes. Cada una tiene una función distinta y no debe tratarse como equivalente a las demás.

## 1. Personas

**Función:** caracterizar necesidades y posibilidades desde la experiencia de las personas estudiadas.

### Datos potenciales

- equipos utilizados o que necesitan mantener funcionando;
- prioridades;
- horas/tiempos de uso;
- simultaneidad;
- autonomía deseada;
- problemas energéticos;
- preferencias;
- criterios de decisión;
- experiencias;
- presupuesto/capacidad de inversión;
- restricciones;
- percepción de precios;
- percepción de disponibilidad;
- canales de búsqueda/adquisición;
- situación laboral;
- fuentes de ingresos;
- ingresos complementarios.

No pedir a las personas conocimientos técnicos que razonablemente puedan derivarse a partir de sus respuestas.

## 2. Internet

**Función:** caracterizar la oferta comercial observada.

### Fuentes potenciales

- sitios web;
- comercios;
- plataformas de anuncios;
- otros espacios públicos de oferta comercial.

### Datos potenciales

- productos;
- categorías;
- marca/modelo;
- especificaciones;
- potencia/capacidad;
- precios;
- moneda;
- vendedores;
- ubicación;
- disponibilidad anunciada;
- fecha de observación;
- garantías;
- composición de kits;
- servicios asociados.

La fecha de observación es importante porque precios y disponibilidad pueden cambiar.

## 3. Instituciones

**Función:** proporcionar contexto y referencias externas para interpretar los resultados.

### Datos potenciales

- estadísticas económicas;
- información energética;
- información territorial;
- población;
- contexto regulatorio;
- otros indicadores relevantes.

Los datos institucionales complementan el análisis y no constituyen automáticamente un objetivo independiente.

## Triangulación

La función de cada fuente es:

- **personas →** experiencia, necesidad y capacidad;
- **Internet →** oferta observada;
- **instituciones →** contexto.

La información debe contrastarse cuando sea pertinente, pero una fuente no valida automáticamente a otra.

## Registro y trazabilidad

Para cada conjunto de datos se debe registrar, cuando corresponda:

- origen;
- fecha;
- método de obtención;
- variables;
- unidades;
- transformaciones;
- filtros;
- supuestos;
- problemas de calidad.

Las fuentes concretas de Internet, la estrategia definitiva de recolección y otros detalles metodológicos permanecen abiertos.
